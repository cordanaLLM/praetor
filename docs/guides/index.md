# Guides

Task guides for adopting, operating and developing Praetor, grouped by what you are doing.
Each group opens with a short index that names the page to read first.

New here? Pick the path that matches your role:

- **Adopting Praetor in a repository**: start with [Fast adoption](../adoption.md).
- **Contributing to Praetor itself**: start with [Contributing to Praetor](contributing.md).
- **Running Praetor on a workstation**: start with
  [Workstation install and status](workstation-update.md).

## Guide groups

- [Adoption and onboarding](adopt/index.md): bring a repository under governance and verify
  what adoption declared.
- [Agents, clients and model routing](agents-and-clients/index.md): agent hooks, client and
  editor configuration, context tools and model routing.
- [Contributing, hooks and CI](contributor-workflow/index.md): local verification, Git hooks,
  the development MCP server and CI caching.
- [State ledger and planning](state-and-planning/index.md): the private ledger, planning
  drafts, wishes, issue sync, resource cleanup and the
  [research and upstream radar](radar.md).
- [Dogfooding](dogfood/index.md): running Praetor against public repositories and repairing
  what fails.
- [Workstations, devcontainers and operations](workstations-and-operations/index.md):
  installing the engine, devcontainers, workstation sync and operational configuration.
- [Build, release and deployment](build-and-release/index.md): release tags, the Helm chart,
  canary upgrades and the builder.
- [Documentation governance](docs-governance/index.md): the Markdown gate, documentation
  drift, text register and the wiki sync.
