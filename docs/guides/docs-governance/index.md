# Documentation governance

These guides cover the rules Praetor's own documentation follows: the Markdown gate, the
check that surface changes ship their documentation, the voice each kind of text uses, and
how the wiki is published.

Read [Documentation governance](../documentation-governance.md) first.

- [Documentation governance](../documentation-governance.md): the locked Markdown gate,
  its formatting rules and the check for links into private session artifacts.
- [Documentation drift](../documentation-drift.md): `scripts/docs_drift.py` requires a
  documentation change with every change to a user-discoverable surface.
- [Text register](../text-register.md): the `register:` policy that names the voice for
  forge, documentation and agent text.
- [GitHub wiki sync](../github-wiki-sync.md): how `docs/wiki/` is mirrored to the
  repository wiki and how pages it no longer carries are removed.
