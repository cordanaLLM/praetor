# Moved: The High-Integrity Systems Standard

This page moved. The standard is named "HISS", not "HISS-16" — HISS-16 names only the
context-integrity invariant inside it, and the standard now covers HISS-01 through
HISS-21. The formal specification lives at **[hiss-spec.md](hiss-spec.md)**.

No `mkdocs-redirects` plugin is configured for this site (`mkdocs.yml` only enables
`search`), so this stub is the redirect mechanism: it keeps every existing link and
bookmark to `standards/hiss-16-spec.md` resolving under `mkdocs build --strict` instead
of breaking the build or 404ing for a reader.
