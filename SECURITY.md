# Security Policy

## Security Issues

Security issues include unauthorized code execution, disclosure of secrets or
private data, and bypasses of repository governance or verification controls in
the CLI, MCP server, generated workflows, or agent hooks.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting: open this repository's **Security**
tab and choose **Report a vulnerability** ([report form](https://github.com/cordanaLLM/praetor/security/advisories/new)). Include the affected version, the
impact, and steps to reproduce the issue.

Do not use public issues to report vulnerabilities.

## Supported Versions

The latest release and the default branch receive security fixes.
